# 判斷紀錄 擷取器 v0.6.0

Chrome → `chrome://extensions` → 開啟「開發人員模式」→「載入未封裝項目」→ 選這個資料夾。

支援 claude.ai、chatgpt.com、gemini.google.com。

## v0.6.0 修了什麼

**認問句，不認回答。**
原本判斷「這輪存過了沒」的指紋是「問句＋回答」。回答在串流中每秒都在長，
介面的狀態字每幾秒換一次，於是同一個問題被存成幾十輪。
現在同一個對話裡一個問句就是一輪，回答從不完整長到完整是同一輪的不同時刻。

**擋掉介面狀態字。**
`3 minutes ago`、`Running page script`、`2m 51s`、`Needs your input` 這些不是 AI 的回答。
擋的是「明顯不是回答的字串」，不是「看起來像重複的字串」——後者會動到真正的原文。

**送出前先扣 30 秒。**
回答還在串流時看起來就已經「停了一下」。原文寫進資料庫之後改不了，
寧可晚 30 秒，不要送一段不完整的進去。

**補抓的舊對話會標明。**
第一次在一個已經聊了好幾輪的對話上跑起來時，畫面上那些是舊的，
時間戳是擷取當下而非發話當下。這種紀錄在 `source` 欄位會講清楚，
不會假裝是即時記的——這套系統的前提是「當下決定，事後不補」。

**一次性清掉本機殘留。**
v0.5.0 存進瀏覽器的假紀錄會在重新載入時自動清掉，不然換了新版還是會被送上去。

## 這個外掛手上有什麼

網址、公開金鑰、一組匯入代碼。就這三樣。
拿這三樣只能呼叫 `redeem_import_code` 一個函式，而那個函式只能寫、
只能寫給代碼的主人、會過期、主人隨時可以撤銷。
**它從來沒有讀取權。**
